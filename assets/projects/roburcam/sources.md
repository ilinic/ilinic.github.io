# RoburCAM project images and sources

Artem states that he worked as Team Lead and Developer on this 2D CAD/CAM project. Technology wording is retained from the existing portfolio at his request. The standalone SolidWorks automation project was removed at his correction; AutoCAD and SolidWorks integration belongs to RoburCAM.

## Product references

- Current English product website: https://www.roburcam.com/en/
- Current features: https://www.roburcam.com/en/features/
- The product is for Euromac CNC punch presses; Salvagnini was an uncertain recollection and was not used.
- Features include drawing import from AutoCAD and SolidWorks, a tool library, automatic tooling, sheet nesting, punch simulation and NC code generation.
- A historical English product brochure independently documents those capabilities: https://web.archive.org/web/20141005083447id_/http://www.roburcam.com:80/pdf/RoburCAM_offer_eng.pdf

The web search index initially returned an obsolete site version. Direct retrieval confirmed the live multilingual site and the English /en/ route. The published portfolio links to the current site, not the archive.
