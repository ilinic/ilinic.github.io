# Inventory Mini screenshot previews

Source repository: https://github.com/ilinic/Inventory-mini

The owner created this application for a small manufacturer. Project behaviour and CSV-based product-list imports were checked against the public README. The Android source contains Java and Kotlin; the web application uses PHP and MySQL.

The images were translated into English with built-in ImageGen for this portfolio. They are presentation previews; the application code was not changed. The original Russian screenshots remain in the source repository.
